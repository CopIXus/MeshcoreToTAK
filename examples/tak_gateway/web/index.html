Settings

Wi-Fi

The gateway needs internet access to reach the TAK server and set its clock. If it cannot join this network for a minute, it opens its own setup Wi-Fi MeshCore-TAK-Setup (password on the OLED, page at 192.168.4.1). Hold the PRG button for 3 seconds to open it at any time.

TAK Server

Create a TAK Portal integration on this host, then use Download Certs. The passphrase (usually atakatak) unlocks the .key file. This browser decrypts the key and only the clear key is sent to the gateway.

Certificate…

Sends markers and mesh chat. Use the integration whose group the ATAK phones receive. The gateway only sends: nothing from TAK goes back onto the mesh.

Paste PEM text instead

Map marker (CoT)

Which nodes go to TAK

Only nodes whose adverts carry a GPS position are considered. A node uses the first enabled filter it matches, top to bottom, and is sent with that filter's icon and color.

Units that match no filter use the default style when this is on, and are not sent when it is off.

Filter

Separate several entries with commas. Case does not matter, and a node matches if it fits any of them.

Role

2 to 4 letters or digits. This is the k= field in the tracker message.

Tracker

Used when the role key is not in the catalog.

MeshCore chat → TAK


Messages heard on these MeshCore channels are posted to a TAK chat room. This is one-way: messages sent in TAK do not go back onto the mesh.






Posts everything said on the MeshCore Public channel into this TAK room.




#name channels need no key. Private channel keys (32 or 64 hex, base64 also accepted) are stored on this device only and are never shown again.


Chat messages are placed on the TAK map at the gateway location set under Gateway node.





MeshCore trackers


A tracker radio sends its name, a short role, and the fix on a private channel. This gateway chooses the icon and color. Those messages are not posted as chat. Turn chat off on a channel that should carry fixes only.




Role catalog


The k= value from the radio. A K9, a vehicle, and a person can share one channel and still look different. Unknown roles use the channel style.





Per-tracker overrides


Optional. A row for one 8-character id wins over the role and the channel style. Leave the callsign blank to keep the name from the radio.

Gateway node












Where this gateway is installed. Pasting "lat, lon" into Latitude fills both. Used for the mesh advert and as the map position of chat messages in TAK.


Mesh advert











Floods a MeshCore advert with this name and location so the gateway shows up in contact lists and on mesh maps. Sent at boot once the clock is set, then on this interval.

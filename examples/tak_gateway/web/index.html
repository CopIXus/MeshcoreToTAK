Gateway node












Where this gateway is installed. Pasting "lat, lon" into Latitude fills both. Used for the mesh advert and the gateway's TAK contact.


Mesh advert











Floods a MeshCore advert with this name and location so the gateway shows up in contact lists and on mesh maps. Sent at boot once the clock is set, then on this interval.





MeshCore chat ↔ TAK


Messages heard on these MeshCore channels are posted to a TAK chat room, and messages sent to that room in TAK go back out on the channel.






Posts everything said on the MeshCore Public channel into this TAK room. Listen only: messages from TAK are not broadcast onto Public.




#name channels need no key. Private channel keys (32 or 64 hex, base64 also accepted) are stored on this device only and are never shown again.


Gateway contact in TAK








TAK users can message this contact directly (goes to the first channel). It is placed at the gateway location set under Gateway node.
